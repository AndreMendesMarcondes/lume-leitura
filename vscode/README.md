# Lume — Leitura com Foco (VS Code)

Ferramentas para ler código e documentação sem perder o foco.

- **Bionic reading** no editor (código, comentários ou só Markdown/texto) e no preview de Markdown.
- **Foco**: esmaece tudo fora da linha ou do parágrafo do cursor.
- **Leitura guiada**: um parágrafo por vez, `Alt+J` / `Alt+K`.
- **Voz alta** com a palavra atual destacada no editor (Windows).
- **Marca-texto com notas**, exportáveis em Markdown.
- **Timer de foco** e **progresso de leitura** na barra de status.
- **Modo leitura**: fonte legível, espaçamento maior e Zen Mode num atalho.

Menu geral: `Alt+L` e depois `M`, ou clique em "Lume" na barra de status.
